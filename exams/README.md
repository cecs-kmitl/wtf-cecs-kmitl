# Exam library

Place UTF-8 `.md` exam files in this folder using the format in `template.md`. Give each file a unique exam ID. Push the changes to the repository to trigger a new Cloudflare Pages build. The build validates each file and adds it to the library; invalid files stop the build.

`README.md` is ignored by the library builder. Every other `.md` file in this folder is published, including its answer key. Do not add confidential exams.
